Submit an MCQ Correction for Review

Revisions made through Question Content Studio can be submitted here. A submission freezes the exact draft version, original MCQ ID and source revision for reviewers. Direct mode bypasses additional review only when Chief authorizes that policy; it still cannot publish to students.

Review Policy

Current policy applies to corrections of existing MCQs. The default requires one independent reviewer. Two-reviewer mode requires two different authorized reviewers, neither of whom authored the draft.

Review policy changes are sensitive actions. The Chief Administrator must complete the existing email security verification. No code is required for ordinary review browsing.

Import & Validate MCQs

Upload a UTF-8 CSV with one question per row. Include each row's Question Bank, Subject, Chapter, Topic, source and all four options. Mixed subjects/chapters are supported. Questions are checked for missing fields, invalid answers, syllabus classification and duplicate rows before review.

CSV and Excel (.xlsx) first-worksheet imports are supported in this development version. Academy-approved master syllabus labels are matched by subject/chapter/topic; temporary legacy MCQ labels are not treated as approved syllabus. Direct student publishing remains disabled.

Quality & Source Protection

Questions in the original Past Papers Question Bank require a traceable source. No AI-generated answer-key corrections are applied. Warnings call for manual academic review.

Approved ordinary banks: SJN Question Bank (new academy-authored drafts) and Past Papers Question Bank (original exam-source content).

Course Tests: remain a separate protected question pool, not imported here. The original source-paper records and immutable student attempt revisions are untouched.

Protected Draft Storage

Store or retrieve unpublished drafts in the separate Management Authentication database. Chief Administrator only. Saving never publishes MCQs to students.

Protected draft storage is available after Management Auth sign-in.

Bulk Topic Spelling Corrections — Review Only

For existing LMS topics with incorrect spelling, prepare a correction proposal without changing student records. Up to 1,000 proposed topic renames per CSV, with exact Subject/Chapter scope and duplicate/collision checks. This is a separate operation from importing new MCQs.

Existing master syllabus labels are not modified by this CSV proposal. For everyday changes use Syllabus & Taxonomy → Rename Selected. Bulk correction plans still require separate review.
